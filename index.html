Repository status

The public support shell is built. Its service loop still needs proof.

FabriconFeedback is the public sidecar for the private aviation game: a support site, privacy record, issue queue, and relay/bridge codebase. This view separates what exists in the repository from what still depends on external service configuration.

Built

Public support foundation

  • Responsive support, feedback, and privacy pages.
  • A GitHub-backed board with search, state, label, and sort controls.
  • A tested Worker implementation for validated, rate-limited issue creation.
  • Public/private issue-bridge workflows and issue templates in source.

Degraded

Account-free submission is not yet proven

The public site and issue browsing remain available, but the no-account submission relay is not currently reachable. Use GitHub Issues directly until the relay is restored and smoke-tested. The private tracker bridge should also be treated as planned setup, not a live promise.
