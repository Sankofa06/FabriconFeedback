Privacy Policy

Fabricon Aerospace keeps gameplay data on your device.

We do not run analytics, advertising trackers, or account systems. Optional feedback is sent only when you submit it.

Data Stored By The App

Fabricon Aerospace stores save data, settings, company progress, and gameplay state locally on your device. This data is used to run the game and is not sent to FabriconFeedback automatically.

Optional Feedback

If you submit feedback from the app or this website, your title, message, selected category, and a small game-state snapshot may be sent to a Cloudflare Worker so it can create a public GitHub issue in Sankofa06/FabriconFeedback.

Public GitHub issues are visible to anyone. Do not include personal, confidential, or private save information in feedback text.

Third Parties

Feedback submission uses Cloudflare Workers for relay hosting and GitHub Issues for public tracking. Email feedback, if used, is handled by your mail app and mail provider.

Contact

Use the Feedback page to open an issue or send feedback from the app.
